# 无畏契约兴趣站

一个用原生 HTML / CSS / JavaScript 制作的静态兴趣网站，介绍我玩《无畏契约》(VALORANT) 的心得与收藏。整体采用游戏标志性的暗色蓝黑 + 战斗红配色。

## 页面结构

| 页面 | 说明 |
|------|------|
| `index.html` | 首页，含欢迎横幅与三大板块入口卡片 |
| `games.html` | 游戏心得，含技能介绍、地图介绍、电竞模块 |
| `reaction.html` | 反应测试，测量你的视觉反应速度 |

首页三张卡片可点击跳转到「游戏心得」页的对应板块。

## 功能亮点

- **反应速度测试**：点击开始后随机 1~4 秒变绿，按下鼠标瞬间计时，记录最快成绩，并支持抢跑判定。
- **返回顶部按钮**：游戏心得页滚动超过 600 像素后显示，点击回到页面顶部。
- **锚点跳转**：首页卡片直达游戏心得页的指定板块。
- **语义化 HTML**：使用 `header` / `nav` / `main` / `section` / `article` / `footer` 等标签。
- **响应式布局**：窄屏下导航与卡片自动换行适配。

## 本地运行

在项目目录下执行：

```bash
python -m http.server 8000
```

然后浏览器访问 <http://localhost:8000>。

## 技术栈

- HTML5 语义化标签
- CSS3（Flexbox / Grid 布局、CSS 变量）
- 原生 JavaScript（DOM 操作、事件监听、定时器、时间戳计时）
